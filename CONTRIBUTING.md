# Contribution boundary

Signalbox is public for reading and study, but no project license or standing
contribution terms have been selected. Repository visibility is not a reuse
grant, and an unsolicited pull request does not by itself supply terms under
which its code, documentation, diagrams, or other material can be accepted.

For now:

- security and privacy reports belong in the private path described in
  [`SECURITY.md`](SECURITY.md);
- public-safe bug reports may identify a reproducible source-contract defect;
- external code or documentation contributions are not accepted or merged
  until the maintainer publishes explicit contribution and rights terms; and
- changes to normative Signalbox contracts require Faye's explicit maintainer
  approval, even when validation passes.

Do not include live endpoints, credentials, private configuration, raw router
readback, account data, or private incident material in any public submission.
